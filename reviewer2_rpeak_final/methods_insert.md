For the revised embedded ECG-to-RR acquisition route, QRS detection was implemented using an established Pan-Tompkins-based detector operating causally at 250 Hz. The detector applied 5-15 Hz bandpass filtering, derivative transformation, squaring, 150-ms moving-window integration, adaptive signal/noise thresholding, refractory logic, and missed-beat search-back using fixed literature-derived temporal constants. The exact revised implementation was externally evaluated on all 48 MIT-BIH Arrhythmia Database records after resampling from 360 Hz to 250 Hz. Expert beat annotations were filtered to standard WFDB beat types and matched one-to-one to detections within +/-150 ms. Hamilton QRS detection was evaluated under the same record, channel, resampling, and matching rules as an independent established comparator. Offline runtime excluded disk loading; ESP32 runtime instrumentation was prepared to measure detector processing time per sample against the 4-ms budget at 250 Hz.
